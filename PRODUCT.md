# Product

## Register

product

## Users

Designers, frontend builders, and people working with coding agents who want to find
interesting design solutions, motion, interactive websites, and useful design resources.

## Product Purpose

Make design discovery pleasant and useful. V1 has an Inspiration collection and a
Useful Sites directory with the user's original compact, hover-expanding list.
Visitors can search, filter, sort, save favorites, and submit links for owner review.
Codex-facing design presets and shaders follow in a later phase. See docs/PRD.md.

## Brand Personality

Curated, expressive, enjoyable. These are the implementation reading of the user's
request for beautiful styling and animation and a site that feels pleasant to use.
Designeer is the reference for a useful discovery tool, with an original interaction.

## Anti-references

No named anti-reference was supplied. Preserve the expanding list rather than
replacing it with the reference's adjacent-preview arrangement. Avoid generic
marketing sections, fake activity, decorative metrics, and effects that obscure browsing.

## Design Principles

- Let the collected work provide visual variety while the interface stays coherent.
- Make motion explain expansion, selection, and feedback.
- Keep source and creator context visible.
- Preserve browsing context through searching, filtering, saving, and sign-in.
- Keep submission receipt separate from approval and publication.

## Accessibility & Inclusion

Use semantic navigation and forms, visible keyboard focus, sufficient text contrast,
keyboard/touch equivalents for hover expansion, controllable video, and reduced-motion
alternatives. No specific formal accessibility certification was requested.
